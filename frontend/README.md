# Console Relais

La commande `npm run dev` démarre la console Next.js, le worker et le récepteur local de recette. La version compilée démarre avec `npm run build && npm start`.

Le [guide du projet](../README.md) indique comment se connecter, appeler les simulations, lancer les tests et exploiter Docker. Les règles de publication, d’accès et de livraison sont détaillées dans le [guide d’exploitation](../docs/exploitation.md).
